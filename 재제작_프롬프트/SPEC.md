# 「생명공학기술 탐험」 웹 수업 자료 — 전체 사양서 (버전 1 기준)

이 문서는 「생명공학기술 탐험」(버전 1)의 기준입니다. AI 코딩 도구에게 그대로 주고 고치거나 다시 만들 때 사용합니다.

---

## 0. 목적과 대상

- **목적**: 고등학교 1학년 「기술」 생명공학기술 단원에서 학생이 16가지 기술의 **원리와 용어**를 단계별 그림으로 정확히 이해하도록 돕는 웹 자료.
- **대상**: 고등학교 1학년. 교사 시연(전자칠판) 또는 학생 개별 기기(노트북·태블릿·휴대폰).
- **설명 수준**: 초등학생도 이해할 수 있는 쉬운 말(해요체)로 설명하되, 용어는 학술 용어를 그대로 쓰고 처음 나올 때 뜻을 풀어 준다.
- **최우선 원칙**: 모든 설명·문항·해설은 정확하고 객관적이어야 한다(7장).
- **참고한 형식**: 풍경 위의 핀을 누르면 단계별 원리 그림이 펼쳐지는 방식(수송 수단의 이해, susong-sudan 저장소).

## 1. 기술 조건

- 정적 웹: `index.html` + CSS + 순수 JavaScript. 빌드 도구·프레임워크·외부 JS 라이브러리 없음.
- 외부 자원은 Google Fonts만(Black Han Sans, IBM Plex Sans KR, IBM Plex Mono). 대체 글꼴 지정.
- 그림은 인라인 SVG. 밝은/어두운 화면(`prefers-color-scheme`) 모두 지원, 모든 색은 CSS 변수.
- 휴대폰 가로 375px에서 가로 넘침 없음. 표는 자체 가로 스크롤.
- 접근성: 탭 `role="tablist"`, ←/→ 이동, 서랍 `role="dialog"`, Esc로 닫기, 포커스 가두기, `prefers-reduced-motion`이면 장식 애니메이션 정지.
- `localStorage`(마지막 탭, 퀴즈 최고 기록)는 모든 접근을 try/catch로 감싼다.
- 해시 주소: `#home`, `#basic`, `#compare`, `#quiz`, `#inquiry`, `#t1`~`#t16`(기술 서랍 바로 열기).

## 2. 화면 구성

- 상단 고정 바: 작은 머리글 `기술·가정 · 생명공학기술`, 제목 **생명공학기술 탐험**(마지막 단어 "탐험" 강조색), 탭 5개(홈, 기초 개념, 개념 비교, 확인 퀴즈, 생각 더하기).
- **홈**: 바이오 시티 풍경(SVG 16:9) + 번호 핀 16개 + 분류별 버튼 4묶음 + 다른 탭 카드 4개.
  - 풍경: 하늘(해, 흐르는 구름), DNA 연구동, 병원·영상, 식물 공장·식품동(3층), 스마트 온실, 동물 우리, 땅속의 세포 세계(염색체, 배양 접시, 바이오프린터 노즐, 나노입자).
  - 핀은 `번호 + 짧은 이름` 알약 버튼. 휴대폰에서는 번호만 보인다.
- **상세 서랍**(오른쪽에서 열림, 휴대폰은 전체 폭): 분류 표시, 이름, 한 줄 요약, 핵심 흐름 칩, 쉽게 말하면, 원리 그림 + 단계 버튼(전체, 1~N) + 단계 설명 + 이전/자동 재생(6초)/다음, 핵심 용어, 어디에 쓰일까요, 알아둘 점(참고/주의), 더 궁금해요(접기), 생각해 보기(접기), 관련 기술 버튼.
- **기초 개념**: 세포→게놈 확대 그림(6단계), DNA 구조, 염기 짝 맞추기 게임, 용어 정리, 더 궁금해요 4개.
- **개념 비교**: 표 8개.
- **확인 퀴즈**: 26문항, 즉시 채점, 해설, 모두 풀면 칭호, 최고 기록 저장, 다시 풀기.
- **생각 더하기**: 토론·조사 질문 10개.

## 3. 디자인

- 콘셉트: 도면(격자) 느낌의 원리 그림 + 밝은 풍경.
- 분류 색: DNA를 다루는 기술(파랑), 세포를 다루는 기술(보라), 먹거리와 농업(초록), 몸을 보고 만드는 기술(청록). 강조색은 주황.
- 원리 그림 규칙: 현재 단계의 부품만 진하게, 나머지는 흐리게. 흐름은 움직이는 점선. 단계 0("전체")은 모든 부품과 흐름 표시.
- 문체: 해요체, 짧은 문장.

## 5. 공통 그리기 규칙

- 원리 그림은 `Diagram.render`로 그린다. 부품(glyph)은 약 40종이며 한 부품은 중심 기준 약 ±28 크기.
- 라벨 글자는 그림 밖으로 나가면 안 된다(각 기술 그림의 `h`는 가장 아래 라벨보다 충분히 크게).
- 한 단계에서 `on`에 없는 부품은 투명도 0.28.

## 6. 동작 확인 목록(완성 조건)

1. 브라우저 콘솔 오류 0개.
2. 홈에 핀 16개, 분류 버튼 16개. 각 핀을 누르면 해당 번호의 서랍이 열리고 주소가 `#tN`으로 바뀐다.
3. `#t1`~`#t16` 주소로 직접 열면 서랍이 열린다. Esc, ✕, 바깥 클릭으로 닫으면 주소가 `#home`이 된다.
4. 16개 서랍 모두 전체 + 각 단계 버튼이 동작하고 그림 라벨이 그림 밖으로 나가지 않는다.
5. 탭 5개 전환, 해시 주소 반영, ←/→ 키 이동.
6. 퀴즈 26문항, 선택 시 정답/오답 표시와 해설, 점수 갱신, 다시 풀기가 같은 탭에 머문다.
7. 염기 짝 맞추기: 올바른 짝만 채워지고 8개를 맞히면 완료 문구가 나온다.
8. 휴대폰 375px 가로 넘침 없음, 어두운 화면에서 글자가 읽힌다.

## 7. 내용 정확성 기준(가장 중요)

1. 세포 ⊃ 핵 ⊃ 염색체 ⊃ DNA ⊃ 유전자. 게놈은 DNA 전체이며 염색체와 같지 않다. X자 염색체는 복제된 염색체.
2. DNA 이중나선의 염기 짝은 A–T(수소 결합 2개), G–C(3개). 정보는 염기 배열 순서에 있다.
3. CAR-T는 유전자 도입(세포융합 아님). 세포융합은 하이브리도마(단일클론항체) 예.
4. 대장균에는 cDNA를 넣는다. 제한효소로 자르고 DNA 연결효소로 붙인다. 재조합 인슐린은 발효 탱크 배양, 돼지는 불필요.
5. 제한효소(정해진 서열)와 유전자가위(설계한 위치)를 구분한다.
6. 동물 조직 배양은 개체를 만들지 못하고, 식물 조직 배양은 개체를 만든다. 미생물 배양과 구분한다.
7. 근비대는 장력이 핵심이며 근육 손상은 필수가 아니다. 근위성세포의 필요성은 연구가 엇갈린다.
8. 줄기세포로 손가락이 재생되지 않는다. 줄기세포 치료는 조직을 보충·복구하는 것이다.
9. 연도·승인 사례(FDA 등)·한국 식품 규제는 바뀔 수 있다. 확신이 없으면 쓰지 말고 "확인 필요"로 남긴다. "~라고 단정"하지 않는 표현(예: 환경에 항상 유리하지 않을 수 있음)을 지킨다.
10. 위험·한계를 숨기지 않는다(종양 위험, 부작용, 윤리 논란, 성공률, 전력 비용, 알레르기, 안전성·독성).
